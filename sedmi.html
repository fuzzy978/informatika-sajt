PyGame

Предуслов за инсталирање библиотеке PyGame је да на рачунару имаш инсталиран Python. Потребно је да у командној линији откуцаш:

pip3 install pygame

Командну линију покрећеш тако што држећи тастер windows притиснеш тастер r и онда откуцаш cmd. Уколико добијеш поруку да команда pip3 не постоји, онда пробај са:

py -3 -m pip install pygame

PyGameBg

Програмски кôд на почетку и на крају програма може се прилично скратити ако се користи библиотека PyGameBg. Њу веома једноставно можеш инсталирати на свом рачунару навођењем команде у командном прозору свог оперативног система:

pip3 install pygamebg

Ако случајно претходна команда не ради, можеш пробати команду:

py -3 -m pip install pygamebg
